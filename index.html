Apps of its own

The tools a desktop should come with.

Store

Every app Arch has, one click away

The Store lists every app Arch's repositories describe, in sections, searched as you type, installed and removed with a click. With the AUR on, community recipes are built and installed the same way, no terminal.

Dr. Help

A check-up, in plain words

Dr. Help looks the system over the way the Arch Wiki's System maintenance asks: failed services, errors in the log, leftover packages, mirrors, firmware, disk health. What it can fix has a button; all of them at once is one password.

Vyntaris Office

Documents, spreadsheets and slides

VDoc, VSheet and VSlide open and save Word, Excel and PowerPoint files, password-protected ones too. VSheet computes old workbooks the way Excel does.

Settings

One place for all of it

Every setting in one file, every one found from the launcher by its name. The look, the bar, power, backups, drivers, users and the language.

Under the hood

Arch Linux, looked after.

Vyntaris is a package from its own pacman repository. Underneath it is plain Arch, updated with pacman -Syu or one click in the island.

update-guard

Updates that undo themselves

A Timeshift snapshot before every upgrade, and a boot entry that goes back to it. If the new system fails to start three times, the old one comes back on its own.

Drivers

Drivers by themselves

Graphics, Wi-Fi, sound, printers and scanners install after each start and when a printer is plugged in. Only the firmware for the hardware you have.

Upkeep

Upkeep on a schedule

The package cache trimmed weekly, SSDs trimmed, Btrfs scrubbed monthly, mirrors kept fast, firmware from fwupd.

Fast

Fast where it matters

Hyprland and Quickshell, the desktop's own tools written in Rust, zram instead of a swap file, the wallpaper drawn without the GPU.

Security

Safe by default

An nftables firewall, signed packages only, and uBlock Origin, Bitwarden and Privacy Badger in Firefox from the start.

Games

Ready for games

Steam with Proton, Lutris, GameMode and MangoHud, set up by typing “set up games” in the launcher.

Download

Install Vyntaris.

One image for every PC with a 64-bit processor and UEFI. It updates itself from then on.

Download the ISO
File
vyntaris-x86_64.iso, the latest release
Checksum
SHA256SUMS
Needs
a 64-bit PC with UEFI, and a USB stick of 4 GB or more

  1. Download the ISO

    It has the installer and the whole desktop, so installing works without the internet.

  2. Put it on a USB stick

    Copy it to a Ventoy stick, or write it to the stick directly (this erases the stick; sdX is the stick):

    sudo dd if=vyntaris-x86_64.iso of=/dev/sdX bs=4M status=progress

  3. Boot it and install

    The installer asks who you are and which disk to use, nothing more. Firefox, the file manager, VS Code and the everyday tools come with it.
