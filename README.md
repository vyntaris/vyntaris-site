# vyntaris.github.io

Vyntaris's website, served by GitHub Pages at https://vyntaris.github.io/:

- `/` the home page, with the desktop's real screenshots (`shots/`, taken by `tools/site-shots.sh` in the
  main repository, with this one checked out beside it);
- `/policy/` the privacy policy, with how the Google Drive backup uses a Google account;
- `/tos/` the terms of service.

Plain HTML, nothing to build. `.nojekyll` keeps GitHub Pages from running Jekyll over it.
