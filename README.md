# vyntaris-site

Vyntaris's website, served by Cloudflare Workers at https://vyntarisos.com/ (straight from this repository: no
build, the output directory is its root):

- `/` the home page (`index.html`, `desk.css`, `js/desk.js`; the laptop is `js/laptop.js`), with the desktop's real screenshots (`shots/`, taken by `tools/site-shots.sh` in the
  main repository, with this one checked out beside it);
- `/wiki/` everything else: installing, questions, what to do when something's wrong, all the numbers;
- `/policy/` the privacy policy, with how the Google Drive backup uses a Google account;
- `/tos/` the terms of service.
