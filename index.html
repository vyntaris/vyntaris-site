Updates that undo themselves

First, a snapshot of the system.

Before every upgrade Timeshift takes one, of the system and never of your files. The last three are kept, and the one from the install always.

Then the new system gets three tries.

The first start after an upgrade is counted. If the desktop comes up, the count is cleared and that's all you ever see of it.

If it can't start, the old one comes back.

After the third try the boot menu takes "Undo the update" by itself: the snapshot goes back, and you are where you were.

Questions

What does it cost? Nothing. Vyntaris is free, and so is everything it installs.

Is it really Arch Linux? Yes. Underneath is plain Arch with its kernel, systemd and pacman; the desktop is a package from Vyntaris's own signed repository, and pacman -Syu updates both.

Can it sit next to Windows? Yes. The installer can put Vyntaris in the free space and leave Windows as it is; the boot menu lists both.

Will my NVIDIA card work? Drivers for graphics, Wi-Fi, sound and printers install by themselves after each start. On a laptop with two graphics cards the NVIDIA one sleeps until an app needs it.

What if an update breaks something? Every upgrade starts with a snapshot, and a system that fails to start three times goes back to it by itself.

Do I need the terminal? No. Apps come from the Store, settings from Settings, repairs from Dr. Help. The terminal is there when you want it.

Can I install apps from the AUR? Yes. Turn the AUR on in the Store and its recipes are built and installed with the same click.

What about games? Type "set up games" in the launcher: Steam with Proton, Lutris, GameMode and MangoHud. Game mode then starts with each game.

Which languages? English, Serbian, German, French, Italian, Spanish, Polish and Portuguese, picked when you install and changed in Settings.

What does it send anywhere? Nothing about you. Backups go to your own Google Drive only if you turn them on; the privacy policy says how.

What do I need to install it? A 64-bit PC with UEFI and a USB stick of 4 GB or more. The image holds the whole desktop, so installing works without the internet.

How do I put it on a USB stick? Copy the ISO to a Ventoy stick, or write it to the stick (this erases it; sdX is the stick): sudo dd if=vyntaris-x86_64.iso of=/dev/sdX bs=4M status=progress
