Under the hood

Arch Linux, looked after.

Vyntaris is a package from its own pacman repository. Underneath it is plain Arch, updated with pacman -Syu or one click in the island.

update-guard

Updates that undo themselves

A Timeshift snapshot before every upgrade, and a boot entry that goes back to it. If the new system fails to start three times, the old one comes back on its own.

Drivers

Drivers by themselves

Graphics, Wi-Fi, sound, printers and scanners install after each start and when a printer is plugged in. Only the firmware for the hardware you have.

Upkeep

The package cache trimmed weekly, SSDs trimmed, Btrfs scrubbed monthly, mirrors kept fast, firmware from fwupd.

Download

Install Vyntaris.

One image for every PC with a 64-bit processor and UEFI. It installs the newest Vyntaris, which updates itself from then on.

Download the ISO
File
vyntaris-x86_64.iso, about 1.6 GB
Checksums
SHA256SUMS, signed in SHA256SUMS.sig
Key
vyntaris.gpg, 567C CD91 2301 A261 B06D AFFF C090 5C46 984D 9F8B

What it needs

  • A 64-bit PC (x86-64) that starts in UEFI mode
  • 30 GB on the disk and 4 GB of memory
  • The internet while installing, by cable or Wi-Fi
  • A USB stick of 4 GB or more

  1. Download the ISO and check it

    In the folder it went to, with SHA256SUMS beside it, check that it arrived whole:

    sha256sum --ignore-missing -c SHA256SUMS

    And that the checksums are Vyntaris's own, with SHA256SUMS.sig and vyntaris.gpg beside them:

    gpg --import vyntaris.gpg && gpg --verify SHA256SUMS.sig SHA256SUMS

  2. Put it on a USB stick

    Copy it to a Ventoy stick, or write it to the stick directly (this erases the stick; sdX is the stick):

    sudo dd if=vyntaris-x86_64.iso of=/dev/sdX bs=4M status=progress

  3. Start from it and install

    Turn Secure Boot off in the PC's firmware setup and start from the stick. The installer asks for the internet, your language and keyboard, the time zone, who you are and which disk. Firefox, the file manager, VS Code and the everyday tools come with it.

Before you install

Secure Boot

Off to start, back on after

The stick starts only with Secure Boot off. Once Vyntaris is installed, vyntaris-secure-boot signs it with keys of your own, and Secure Boot can go back on.

Windows

Next to Windows

The installer can use a disk's free space, or one partition of 30 GB or more, and leave Windows as it is. Make room in Windows first (Disk Management, Shrink volume), and with BitLocker keep its recovery key at hand.

Your files

Copy them somewhere first

"Whole disk" erases everything on it. Snapshots keep the system, never your files, so copy what matters elsewhere before you install.

Graphics

NVIDIA, AMD and Intel

Their drivers install by themselves. On a laptop with two graphics cards, the NVIDIA one sleeps until a game or prime-run wakes it.

Updates

Rolling, from Arch

Updates come when they're ready, from Arch and from Vyntaris, with a snapshot taken before each one. There are no big upgrades to wait for.

Help

Something wrong?

See Help, or tell us on the issue tracker. Dr. Help in Vyntaris gathers what the system says, without your names and addresses, and shows it to you first.
