Installing, step by step

You need a 64-bit PC that starts in UEFI mode, 30 GB on the disk, 4 GB of memory, the internet (cable or Wi-Fi) and a USB stick of 4 GB or more. Installing takes about 15 to 30 minutes, most of it downloading.

1. Save your files

If you install on a whole disk, everything on it is erased. Copy what matters to another disk or to the cloud first. Installing next to Windows leaves Windows and its files alone, but a copy is still wise.

2. Download the ISO

Download vyntaris-x86_64.iso (about 1.6 GB). To check that it arrived whole and is really Vyntaris's, see the download section; it's optional, but a good habit.

3. Put it on a USB stick

Writing the ISO erases the stick.

  • From Windows: Rufus. Pick the stick and the ISO, press Start, and when it asks, choose Write in DD Image mode.
  • From Linux: sudo dd if=vyntaris-x86_64.iso of=/dev/sdX bs=4M status=progress, where sdX is the stick (lsblk lists the disks; pick the wrong one and it's erased).
  • Ventoy: copy the ISO onto a Ventoy stick like any other file.

4. If Windows stays: make room for Vyntaris

In Windows, open Disk Management, right-click the largest partition, choose Shrink Volume and free at least 30 GB. Leave the space empty. If the disk uses BitLocker, write down its recovery key first (Settings → Privacy & security → Device encryption, or your Microsoft account): Windows may ask for it once after the change.

5. Turn Secure Boot off

The stick starts only with Secure Boot off. Restart into the PC's firmware setup (usually F2, Del or F10 as it starts; from Windows: Settings → System → Recovery → Advanced startup → UEFI Firmware Settings), find Secure Boot, set it to Disabled, save and exit. After installing, you can turn it back on; see the question about it.

6. Start from the stick

With the stick plugged in, restart and open the boot menu: usually F12 (Dell, Lenovo, Acer), F11 (MSI), F8 (ASUS) or Esc then F9 (HP). Pick the USB stick (if it's listed twice, the one marked UEFI). Choose Vyntaris in the menu that appears.

7. Answer the installer

The installer opens by itself and asks, one page at a time:

  • Internet: plug in a cable, or pick a Wi-Fi network and type its password.
  • Language & keyboard: the installer switches language at once. Try the layout in the field below it.
  • Time zone.
  • You: your name, a user name (lowercase letters and digits), the computer's name and a password. This password also unlocks the screen and approves changes to the system, so remember it.
  • Disk: where Vyntaris goes.
    • Whole disk erases the disk you pick.
    • Free space uses the room you made in step 4 and touches nothing else.
    • One partition erases only the partition you pick (30 GB or more).
    Keep Btrfs unless you have a reason not to: it's what makes updates undo themselves.
  • Summary: read it once more, then Install (or Erase and install).

The computer can stay alone while it installs. When it says Vyntaris is installed, take out the stick and restart.

8. The first start

Log in with the password you chose. A short welcome asks for light or dark, the accent colour and the wallpaper, and offers the extras (games, for one). Drivers for your hardware install by themselves in the first minutes; a notification says when, and whether a restart is needed.

The first minutes

  • Tap SUPER (the Windows key) for the control center: Wi-Fi, Bluetooth, sound, brightness, the calendar and notifications. Start typing to search apps, files and settings.
  • SUPER+A shows every app. SUPER+ENTER opens the terminal, SUPER+E the files, SUPER+B the browser.
  • SUPER+Q closes a window. Windows place themselves side by side; SUPER+SHIFT+SPACE lets one float freely.
  • SUPER+I opens Settings, and SUPER+F1 lists every shortcut.
  • SUPER+ESC is the power menu: lock, sleep, restart, shut down.
  • The Store installs apps with a click. Dr. Help checks the system and fixes what it can: type check my system after tapping SUPER.
  • Plain words work in the search: volume 40, dark mode, turn bluetooth off, 100 eur to usd, timer 5m.

Questions

Is Vyntaris free?

Yes, to download, install and use. It's free software under the GNU GPL, and its source is on GitHub.

Can it sit next to Windows?

Yes. Make room in Windows (step 4) and choose Free space or One partition. A menu at start lets you pick Vyntaris or Windows; it stays hidden when there's only Vyntaris.

How do updates work? Can one break my computer?

Updates come from Arch Linux and Vyntaris whenever they're ready; the island shows when some are waiting, and one click installs them. Before every update a snapshot of the system is taken. If an update stops Vyntaris from starting, it gets three tries, then the start menu's Undo the update puts the system back by itself. Your files are never part of a snapshot, so going back never touches them.

How do I install an app that isn't in the Store?

The Store lists every app from Arch Linux's repositories. More come from the AUR, which anyone can upload to: turn it on in Settings → Apps, read the warning on each, and the Store builds it for you. In the terminal, pacman and yay work as on any Arch Linux.

Can I play games?

Yes. Tap SUPER and type set up games: it installs Steam with Proton, Lutris, GameMode and MangoHud. Game mode starts by itself with a fullscreen game.

Does it work with NVIDIA?

Yes, the driver installs by itself. On a laptop with two graphics cards the NVIDIA one sleeps until it's needed; a yellow dot in the bar shows when it's awake, and its panel says which app woke it.

Can I turn Secure Boot back on?

Yes. In the firmware setup, put Secure Boot into Setup Mode (sometimes called "Clear keys"), start Vyntaris, and in the terminal run vyntaris-secure-boot. It signs Vyntaris with keys of your own; then turn Secure Boot back on.

Does Vyntaris collect my data?

No. It has no accounts, no telemetry and no analytics. What it connects to, and why, is in the privacy policy.

How do I back up my files?

Open Backup, sign in to Google Drive and pick the folders. It backs them up at every start, when you shut down, or only when you ask. Snapshots, in Settings → Backups, keep the system, not your files.

How do I change the language?

Settings → Date, time & language. It takes effect at the next login. Vyntaris speaks English, Serbian, German, French, Spanish, Italian, Portuguese and Polish.

Is it Arch Linux? Does the Arch Wiki apply?

Underneath, yes: the same kernel, packages and pacman, straight from Arch. The Arch Wiki applies to everything below the desktop.

When something doesn't work

The USB stick doesn't start

  • Check that Secure Boot is off (step 5).
  • In the boot menu, pick the entry for the stick marked UEFI.
  • If it was written with Rufus, write it again in DD Image mode.
  • Try another USB port, preferably one straight on the computer rather than a hub.

The installer shows a black screen

Some graphics cards don't start the graphical installer. In the menu where you picked Vyntaris, press e, add installer=text at the end of the line, and press Enter. The same questions are then asked in text. The graphical installer also offers Use the text installer on its first page.

No internet in the installer

A network cable is the surest way. If the Wi-Fi isn't listed, the chip may need a driver that installs only after Vyntaris is in place: use a cable, or share your phone's connection over USB (USB tethering).

The installation failed

The installer shows why. If it mentions keys or signatures, the computer's clock is usually wrong: open the installer's terminal, run fix-keyring, and install again. If the download was cut off, check the internet and try again.

Vyntaris doesn't start after an update

Restart, up to three times. After the third failed start, Vyntaris goes back to how it was before the update by itself, and tells you so when you log in. You can also pick Undo the update in the start menu (hold Space while the computer starts to show it), or use Settings → Backups → Undo last update while it still runs.

Vyntaris doesn't start at all

Start from the USB stick, and on the installer's first page choose Repair an installed Vyntaris. It can go back to any snapshot, make the boot images again, finish an interrupted update, or open a terminal inside the installed system. Your files stay as they are.

The desktop froze or disappeared

The bar and the desktop restart by themselves within seconds. If it happens again and again, Vyntaris goes back to the login screen. One app that uses up the memory is closed before the whole desktop freezes.

Something else

  1. Open Dr. Help (tap SUPER, type check my system). It finds the most common problems and puts a fix next to each one.
  2. If that doesn't solve it, choose Report a problem in Dr. Help. Write what went wrong; it adds what the system says, takes out your names and addresses, and shows you everything before it goes.
  3. Or open an issue on GitHub yourself.
