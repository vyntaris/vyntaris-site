    Apps of its own

    The tools a desktop should come with.

    Dr. Help

    A check-up, in plain words

    Dr. Help looks the system over the way the Arch Wiki's System maintenance asks: failed services, errors in the log, Arch's news, leftover packages, mirrors, firmware, disk health, the package cache, SSD trimming, Btrfs scrubs. What it can fix has a button; all of them at once is one password. Its Report files a problem on GitHub with personal details taken out.

    Store

    Every app Arch has, one click away

    The Store lists every app Arch's repositories describe, in sections, searched as you type, installed and removed with a click. With the AUR on, community recipes are built and installed the same way, no terminal.

    Vyntaris Office

    Documents, spreadsheets and slides

    VDoc, VSheet and VSlide open and save Word, Excel and PowerPoint files, password-protected ones too. VSheet computes old workbooks the way Excel does. They come from the Vyntaris repository.

    Under the hood

    Arch Linux, looked after.

    Vyntaris is a package from its own pacman repository. Underneath it is plain Arch, updated with pacman -Syu or one click in the island.

    update-guard

    Updates that undo themselves

    A Timeshift snapshot before every upgrade, and a boot entry that goes back to it. If the new system fails to start three times, the old one comes back on its own and the desktop tells you.

    Install

    Three steps, no questions you don't need.

    Download the ISO

    One image for every PC with a 64-bit processor and UEFI.

    Download Vyntaris 1.0.0

    Put it on a USB stick

    Copy it to a Ventoy stick, or write it directly:

    sudo dd if=vyntaris-1.0.0-x86_64.iso of=/dev/sdX bs=4M status=progress

    Boot and install

    The installer asks who you are and which disk to use, nothing more. Everyday apps come with it: Firefox, the file manager, VS Code, a calculator, an image viewer, a text editor, disk and system tools.
